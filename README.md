# GasSafe — Site Institucional

Projeto de extensão desenvolvido em grupo para criar o site institucional da **GasSafe**, uma proposta de empresa especializada na venda de detectores de gases inflamáveis.

## Objetivo

Desenvolver um site para apresentar a GasSafe, divulgar seus produtos e disponibilizar informações de contato.

## Sobre a GasSafe

A GasSafe é uma proposta de empresa voltada à comercialização de detectores de gases inflamáveis, com foco na segurança e na prevenção de acidentes relacionados a vazamentos.

## Conteúdo planejado

- Apresentação da empresa.
- Informações sobre os detectores de gases inflamáveis.
- Canais de contato.

## Status do projeto

O projeto está em fase inicial de organização e desenvolvimento. Este README será atualizado conforme a equipe definir as tecnologias, criar as páginas e concluir as funcionalidades.

## Finalidade acadêmica

Este site faz parte de um projeto de extensão e está sendo desenvolvido para fins acadêmicos.
